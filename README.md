# Kishor Sortur — Product Portfolio

A responsive, animated single-page portfolio built from scratch for GitHub Pages.

## Included
- `index.html` — portfolio content and structure
- `styles.css` — responsive design, animations and theme
- `script.js` — scroll reveal, counters, navigation and interactive case-study modals
- `assets/kishor-sortur.jpg` — uploaded professional photo
- `assets/Kishor_Sortur_Resume.pdf` — resume linked from the navigation

## Deploy to GitHub Pages
1. Create a repository (for example `kishorsortur.github.io`).
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from branch → main / root**.
4. Your portfolio will be served from the repository's GitHub Pages URL.
