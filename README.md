# Portfolio Philosophy

This portfolio is built around three principles:

### 01 — Start with the problem

Understand the user, context and underlying problem before jumping into solutions.

### 02 — Make prioritization explicit

Use evidence and frameworks such as RICE, AARRR, funnels and cohort analysis to make product decisions explainable.

### 03 — Build and measure

Turn product thinking into tangible artifacts — prototypes, PRDs, roadmaps, metrics and case studies — and define how success should be measured.
